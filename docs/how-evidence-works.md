# How evidence works

Research Wiki keeps source authority separate from every view generated for search, navigation, or synthesis.

```text
immutable sources
  -> versioned document catalog
  -> permission-filtered retrieval units
  -> exact citation fetch
  -> verified claims
  -> disposable wiki, table, and answer projections
```

## Authority layers

1. **Source observation** records where and when bytes were observed.
2. **Document version** identifies immutable content independent of a path or filename.
3. **Evidence span** addresses a passage, page region, table cell, or structured observation.
4. **Retrieval unit** helps find evidence but is never a new source of truth.
5. **Claim** states an interpretation and links to its evidence.
6. **Presentation** arranges verified claims for a reader without changing their authority.

## Exact and narrative evidence

Exact numeric claims require a verified structured source with complete dimensions. Source text can support a cited narrative even when it cannot support normalization or reconciliation. Similarity, model confidence, and visual presentation never increase evidence authority.

## Generated projections

Indexes, summaries, wiki pages, charts, and unified tables are reproducible views. Deleting one must not delete or rewrite the source evidence it references.
