# Versioning and conflicts

A document identity excludes its path and filename. The same bytes observed at multiple locations form one immutable version with multiple source observations.

## Time axes

- **Reporting period** — the economic period described by the content.
- **Source observation time** — when the system saw the source.
- **Knowledge time** — when the system learned a claim.
- **Valid time** — when a claim is considered true in its domain.
- **Event time** — when an underlying event occurred.

Keep these axes separate. A publication date does not replace a reporting period.

## Revisions

Never overwrite old evidence. A newer version may supersede an older one while both remain addressable. Historical research binds to the frozen version set it used; live research rechecks the current version before emission.

## Conflicts

Preserve mirrors, translations, restatements, and disagreements. Source ranking may guide review but must not erase a conflict. A claim should state which version it uses and why other versions were excluded or retained as limitations.
