# Contributing

Read the repository [contribution guide](https://github.com/Kitkitkittt/research-wiki/blob/main/CONTRIBUTING.md). Run `python3 scripts/validate_public.py` before opening a pull request.

Public examples use invented entities and placeholder hosts. Skills define triggers, ordered steps, completion criteria, evidence handling, and abstention behavior.
