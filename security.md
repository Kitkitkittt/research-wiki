# Security

Read the repository [security policy](https://github.com/Kitkitkittt/research-wiki/blob/main/SECURITY.md) and the [public security model](https://kitkitkittt.github.io/research-wiki/docs/security-model/).

Report vulnerabilities through GitHub's private vulnerability reporting. Keep credentials, private endpoints, source documents, and exploit details out of public issues.
