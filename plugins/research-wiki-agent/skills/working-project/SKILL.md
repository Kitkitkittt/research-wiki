# Working project

## Workflow

1. **Create scope** — name the research question, entities, periods, answer class, and evidence boundary.
2. **Collect references** — store citation and document-version references rather than copying source bodies as new authority.
3. **Write claims** — label observations, interpretations, assumptions, forecasts, risks, catalysts, and open questions.
4. **Revalidate** — re-fetch citations before displaying, sharing, or exporting a material claim.
5. **Append** — preserve project history and supersession; do not overwrite earlier evidence or conclusions silently.
6. **Separate publication** — keep editable analyst work outside sealed evidence. Publish a source or correction only through the governed intake and review workflow.
7. **Export** — include citations, limitations, version time, and unresolved conflicts with the narrative.

## Completion criterion

Complete only when every material project claim has a current evidence reference or an unresolved label, project history remains append-only, and no editable note is represented as source authority.
