# Evidence-first research

## Workflow

1. **Classify** — identify the requested answer class: exact fact, cited narrative, discovery, or automatic.
2. **Scope** — resolve stable entities, periods, document families, report scope, units, and access lane. Stop when ambiguity remains.
3. **Discover** — list only tools available to the authenticated caller and select the narrowest capable operation.
4. **Retrieve** — search within the authorized scope. Treat similarity as candidate discovery, never authority.
5. **Open** — fetch the exact cited passage, table cell, page, or structured observation for every candidate claim.
6. **Verify** — confirm current version, source dimensions, authority, quality, and claim-to-citation support.
7. **Synthesize** — write only from verified evidence. Preserve disagreements, restatements, and source wording.
8. **Limit** — state every unsupported, partial, ambiguous, stale, or unauthorized part.

## Exact facts

Use only verified structured observations with matching entity, metric, period, unit, scale, currency, scope, and citation. Source text, OCR, embeddings, and model confidence can support discovery or narrative context but cannot authorize an exact fact.

## Completion criterion

Complete only when every material claim and displayed number maps to current authorized evidence, and every unsupported part has a typed limitation. If the requested answer class cannot be met, abstain rather than silently downgrade.
