# Financial analysis

## Workflow

1. **Define the fact** — resolve entity, metric, period basis, fiscal period, report scope, assurance, actuality, currency, unit, and scale.
2. **Select authority** — use verified structured facts for exact values and cited source text for narrative explanation.
3. **Retrieve** — find relevant statements, notes, and source tables within the authorized scope.
4. **Open cells** — fetch every source cell used in a displayed number, formula, subtotal, or comparison.
5. **Check dimensions** — reject mixed currencies, units, scales, scopes, actuality, or incompatible periods.
6. **Calculate** — use only approved formulas over verified observations; show inputs and preserve precision.
7. **Explain** — distinguish reported facts from interpretation, forecast, assumption, and scenario.
8. **Limit** — abstain from exact output when verified dimensions or citation closure are missing.

## Completion criterion

Complete only when every displayed value has one verified source observation and complete dimensions, every calculation names its inputs, and narrative claims cite their source passages.
